# Discipline Reset

The 30-Day Discipline Reset app, by José Manuel Cruz Ortiz. Built with Expo (SDK 58), Expo Router, and TypeScript. Daily lessons, habit tracking, and weekly reviews stay on the device: there is no account and no backend.

**Live site:** https://cryp2x1.github.io/discipline-reset/

## Run locally

```bash
npm install
npx expo start
```

In a browser: `npx expo start --web`. Typecheck with `npx tsc --noEmit`.
